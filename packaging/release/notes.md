## Download

| Platform | File | How to install |
|---|---|---|
| macOS (Apple silicon) | `prism-{version}-macos-aarch64.dmg` | Open the DMG and drag **Prism** onto the **Applications** folder next to it. |
| Windows x64 | `prism-{version}-windows-x64.msi` | Run the installer. |

The `.app.zip` file is the in-app update package: installed copies download it through
**Help › Check for Updates…**, so you don't need it to install Prism.

If macOS says Prism can't be opened the first time, open **System Settings › Privacy & Security**
and choose **Open Anyway** for Prism, then open it again.
