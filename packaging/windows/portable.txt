Prism portable mode

While this file sits next to prism.exe, Prism keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PrismData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Prism with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Prism) instead.
If PrismData can't be written (for example on a read-only drive), Prism says so and
uses %APPDATA%\Prism instead.
